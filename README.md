# my-ableton-project-downgrader

이 토이 프로젝트는 **Ableton Live 12**에서 생성된 `.als` 세트 파일을 **Ableton Live 11**에서도 열 수 있도록 변환하는 프로그램이며, AI가 99%의 코딩을 한 만큼, 무료 오픈소스 도구로 공개합니다. Flutter로 작성된 데스크톱 애플리케이션이며 Windows와 macOS를 모두 지원합니다. 에이블톤 프로젝트 협업 중 저와 같이 에이블톤 11에 머물러 있어 에이블톤 12 유저들의 프로젝트 파일을 열어볼 수 없는 사용자들의 겪는 호환성 문제를 해결하는 것을 목표로 합니다.

## 특징

- **다중 플랫폼 GUI** – 파일 또는 폴더를 선택해 한 번에 여러 `.als` 파일을 변환할 수 있는 직관적인 인터페이스를 제공합니다.
- **타깃 버전 선택** – Ableton Live 11의 하위 버전 목록에서 원하는 버전을 선택해 변환할 수 있습니다. 지원 버전 목록은 `AbletonVersion` 클래스에 정의돼 있으며, minor와 patch 번호를 조합해 `"11.x.y"` 형태로 표시됩니다.
- **일괄 변환** – 지정한 폴더 내 모든 `.als` 파일을 재귀적으로 찾아 일괄 변환할 수 있습니다.

## 어떻게 동작하나요?

`.als` 파일은 실제로 GZIP으로 압축된 단일 XML 문서이기 때문에 간단한 세 단계의 규칙을 통해 파일을 처리할 수 있습니다:

1. **압축 해제** – `GZipDecoder`를 사용해 `.als` 파일을 GZIP 압축에서 풀어 XML 문서로 변환합니다.
2. **XML 수정** – 최상단 `<Ableton>` 요소의 `MinorVersion`과 `Creator` 속성을 목표 버전에 맞게 수정하고, 새 버전에서 사용되는 `<MidiEditorLaneModel>` 태그를 구 버전의 `<ExpressionLane>` 태그로 바꿉니다.
3. **재압축** – 수정된 XML을 UTF‑8로 인코딩한 뒤 `GZipEncoder`로 다시 GZIP 압축하여 새로운 `.als` 파일을 생성합니다.

이 과정은 GUI에서 한 번의 클릭으로 실행되며, 변환된 파일은 원본 이름에 `_downgraded` 접미사를 붙여 동일한 디렉터리에 저장됩니다.

## 지원하는 버전

현재 앱은 Ableton Live 11의 모든 minor/patch 조합을 지원합니다. 지원 목록은 아래와 같으며, 추후 업데이트될 수 있습니다:

- 11.3.42, 11.3.41, 11.3.40, 11.3.35, 11.3.30, 11.3.26, 11.3.25, 11.3.22, 11.3.21, 11.3.20, 11.3.13, 11.3.12, 11.3.11, 11.3.10, 11.3.4, 11.3.3, 11.3.2
- 11.2.11, 11.2.10, 11.2.7, 11.2.6, 11.2.5
- 11.1.6, 11.1.5, 11.1.1
- 11.0.12, 11.0.11, 11.0.10, 11.0.6, 11.0.5, 11.0.2, 11.0.1

드롭다운 메뉴에서 minor 버전을 선택하면 해당 minor에서 지원되는 patch 번호가 자동으로 나열됩니다.

## 설치 및 실행

이 프로젝트는 Flutter 애플리케이션입니다. 개발 환경에서 실행하려면 Flutter SDK가 필요합니다.

```bash
# 레포지토리를 클론합니다
git clone https://github.com/shhommychon/my-ableton-project-downgrader.git
cd my-ableton-project-downgrader

# develop 브랜치 체크아웃
git checkout develop

# 의존성 설치
flutter pub get

# 앱 실행 (macOS 또는 Windows에서)
flutter run -d windows  # 또는 -d macos
```

앱을 빌드하여 배포용 바이너리를 생성하려면 Flutter의 `flutter build macos` 또는 `flutter build windows` 명령을 사용하세요. 변환 테스트를 명령줄에서 실행하려면 다음과 같이 할 수 있습니다:

```bash
dart run test/manual_conversion_test.dart "/path/to/your/project.als" "11.3.26"
```

## 사용법

1. **파일 또는 폴더 선택** – 앱을 실행한 후 “단일 파일 선택” 또는 “폴더 선택” 버튼을 클릭해 `.als` 파일을 지정합니다.
2. **목표 버전 선택** – 변환할 Ableton 11 버전을 minor, patch 드롭다운에서 선택합니다.
3. **변환 실행** – “변환 실행” 버튼을 누르면 선택한 모든 파일이 지정한 버전으로 변환됩니다. 진행 상태는 화면 하단에 표시됩니다.
4. 변환된 파일은 원본과 같은 폴더에 `_downgraded.als` 이름으로 저장됩니다. macOS에서는 같은 디렉터리에 쓰기 권한을 부여해야 할 수 있습니다.

## 한계와 유의사항

- **기능 축소** – 이 도구는 XML 헤더를 패치하고 특정 태그 이름만 치환합니다. Ableton 12에서 도입된 새로운 기능이나 데이터 구조는 변환 과정에서 제거되거나 무시됩니다. 따라서 변환된 프로젝트가 완벽하게 동일하게 재현되지 않을 수 있습니다.
- **파일 손상 위험** – `.als` 파일 구조를 이해하지 못한 채 임의로 수정하면 손상될 수 있습니다. 변환 전에 반드시 원본 파일을 백업하세요.
- **호환성 미보장** – 본 도구는 Ableton Live 11에서 파일을 열 수 있도록 도와주지만, 모든 프로젝트가 정상적으로 열리거나 재생된다는 보장을 제공하지 않습니다. 특히 특정 플러그‑인이나 미지원 기능을 사용하는 경우 문제가 발생할 수 있습니다.

## 향후 개발 계획

- **호환성 개선** – Ableton 12에서 새롭게 도입된 구조 요소를 더 많이 파악하여 변환 로직을 보완할 예정입니다.
- **패키징 및 배포** – macOS/Windows 실행 파일과 서명된 설치 패키지를 제공하여 비기술적 사용자들도 쉽게 사용할 수 있도록 할 예정입니다.
